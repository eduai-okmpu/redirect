# Бағыт — динамикалық QR кодтар

Қазақша QR басқару сервисі. GitHub Pages + Supabase Auth/Postgres.

Сайт: https://eduai-okmpu.github.io/redirect/

`index.html` — сыртқы CDN қажет етпейтін дайын сайт. Толық бастапқы код, npm конфигурациясы, SQL миграциясы және тесттер `bagyt-source.zip` мұрағатында.

Supabase Auth URL Configuration ішінде Site URL және Redirect URLs: `https://eduai-okmpu.github.io/redirect/`. Құпия service_role кілтін браузерге қоспаңыз.

Жариялау: Settings → Pages → Deploy from a branch → main → / (root).
